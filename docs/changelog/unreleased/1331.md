## Fixed

- Fixed a zcashd-compat sidecar occasionally staying one block behind zakurad
  until the next block arrived. Requests that zcashd can leave unanswered no
  longer hold up the block announcements the sidecar follows: zakurad only asks
  the sidecar for new blocks if it advertised more blocks than zakurad has, and
  no longer waits for its replies to mempool and peer-address requests
  ([#1331](https://github.com/zakura-core/zakura/pull/1331)).
